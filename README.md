# fungc-unity-course: uGUIの表示・操作を学ぼう

FUN GC の Unity 講座「【Unity基礎】uGUIの表示・操作を学ぼう」で使う教材です。
**Unity プロジェクト本体は含まれていません**(スクリプトなどの教材だけです)。
対象は FUN GC の部員です。

## 回ごとのフォルダ

| フォルダ | 講座 |
|---|---|
| [`lesson1`](lesson1) | 第1回 画面を組み立てよう |

各フォルダに、その回の `README.md`(中身と使い方)、`scripts/`(スクリプト)、講座のスライド(PDF)が入っています。
使いたい回のフォルダを開いて、スクリプトを自分の Unity プロジェクトにドラッグ＆ドロップして使います。
第2回・第3回は、講座が近くなったら追加します。

## 注意

- ファイル名とクラス名は同じにしてください(例: `StatusView.cs` なら `class StatusView`)。
- 同じ名前のファイルは、段階ごとに1つずつ置き換えて使います(詳しくは各回の README)。
- 画像やフォントなどの素材は入っていません。用意の仕方は各回の README の「使う素材」を見てください。
- 演習の解答例は、講座のあとに別途配布します。
- 動作確認は Unity 6 を想定しています(まだ実機確認はしていません)。
