# fungc-unity-course: オブジェクト指向をC#で学ぼう

FUN GC の Unity 講座「【Unity基礎】オブジェクト指向をC#で学ぼう」で使う教材です。
**Unity プロジェクト本体は含まれていません**(スクリプトなどの教材だけです)。
対象は FUN GC の部員です。

## 回ごとのフォルダ

| フォルダ | 講座 |
|---|---|
| [`lesson0`](lesson0) | 第0回 UnityとC#の超入門 |
| [`lesson1`](lesson1) | 第1回 クラスとインスタンス |
| [`lesson2`](lesson2) | 第2回 カプセル化 |
| [`lesson3`](lesson3) | 第3回 継承 |
| [`lesson4`](lesson4) | 第4回 ポリモーフィズムとインターフェース |

各フォルダに、その回の `README.md`(中身と使い方)、`scripts/`(スクリプト)、講座のスライド(PDF)が入っています。
使いたい回のフォルダを開いて、スクリプトを自分の Unity プロジェクトにドラッグ＆ドロップして使います。

## 注意

- ファイル名とクラス名は同じにしてください(例: `Hello.cs` なら `class Hello`)。
- 同じ名前のファイルは、回ごと・段階ごとに1つずつ置き換えて使います(詳しくは各回の README)。
- 演習の解答例は、講座のあとに別途配布します。
- 動作確認は Unity 6 を想定しています。
