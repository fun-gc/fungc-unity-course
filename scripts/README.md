# 第4回 ポリモーフィズムとインターフェース

【Unity基礎】オブジェクト指向をC#で学ぼう 第4回の教材スクリプトです。

使い方: 使うフォルダの `.cs` を Unity プロジェクトの Assets にドラッグ＆ドロップします。
`GameManager` は空のゲームオブジェクトに付けて、再生して Console を見ます。
フォルダは前のものと入れ替えて使ってください(同じクラス名が重なるとエラーになります)。

| フォルダ | 内容 | 期待する Console 出力 |
|---|---|---|
| `01_try` | 同じ Attack() なのに結果が違う | ぺちぺち / 攻撃 / ファイア！ |
| `02_list` | List<Enemy> と foreach でまとめて Attack | ぺちぺち / 攻撃 / ファイア！ |
| `03_interface` | IDamageable を Enemy が実装 | 上に加えて「残り hp: 7」 |
| `04_exercise` | 演習の穴埋めひな型(TODO 1〜4) | 完成すると 02 と同じ |

`hp` は第3回に合わせて `protected` です。
